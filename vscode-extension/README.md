# STEP Learn for VSCode

STEP Learnと連携して動く拡張機能です

STEP Learnへのアクセス権がないとこの拡張機能は意味をなしません

## 自動配布機能

### 使い方

1. この拡張機能を VS Code に入れます
2. STEP Learn でファイル自動配布のアイテムを開き、「VS Code で開く」を押します
3. ブラウザが VS Code を開いてよいかを確認したら、許可します
4. 初めてのサーバーのときは「ファイルを受け取りますか？」と聞かれるので、「受け取る」を押します

ファイルは `ドキュメント/STEP Learn/<コース名>/<アイテム名>` に用意され、そのフォルダーが VS Code で開きます。同じコースに同じ名前のアイテムがあるときは、あとから開いたほうを `<アイテム名> (2)` のような別のフォルダーに用意します。

### 2 回目から

- もう一度「VS Code で開く」を押すと、前に用意したフォルダーをそのまま開きます
- 先生がファイルを追加・更新していたときは、取り込むかどうかを聞きます。取り込んでも、自分で書き換えたファイルは上書きしません
- 「別のフォルダーに用意し直す」を選ぶと、`<アイテム名> (2)` のような新しいフォルダーに最初の状態で用意します

### データの同期

先生が「データを同期する」にしたアイテムでは、用意したフォルダーのファイルを保存するたびに、その内容が STEP Learn に送られ、変更履歴として記録されます。記録は先生と自分が、STEP Learn の画面から見られます。

- 最初に「データを同期するアイテムです」と確認します。「同期して続ける」を押すまで、内容は送りません
- 同期しているあいだは、ステータスバーに「STEP Learn 同期中」と表示します
- 送るのは、用意したフォルダーの中の文字のファイル（1 つ 256KB まで）です。`.git`・`node_modules`・`__pycache__`・`.venv` などと、画像などの文字でないファイルは送りません。フォルダーの外のファイルは送りません
- ネットワークにつながっていないときは、つながったあとにまとめて送ります
- 「STEP Learn 同期できません」と表示されたら、STEP Learn の画面の「VS Code で開く」をもう一度押してください

### 設定

| 設定 | 内容 |
| --- | --- |
| `stepLearn.folder` | ファイルを用意する場所。空のときは「ドキュメント/STEP Learn」 |

### コマンド

- **STEP Learn: 配布ファイルの保存先を開く** — 用意したファイルの場所をエクスプローラーで開きます
- **STEP Learn: ファイルを受け取ってよいサーバーの記録を消す** — 「受け取る」を押したサーバーの記録を消します

## 安全のために

- ファイルを受け取るのは、STEP Learn の画面から開いたリンクに書かれたサーバーだけです。初めてのサーバーでは必ず確認します
- リンクに含まれる鍵は数分で切れ、1 回しか使えません。パスワードを拡張機能に入れることはありません
- 用意するフォルダーの外にはファイルを書き込みません。受け取ったファイルは、STEP Learn が示したハッシュと照らし合わせてから書き込みます
