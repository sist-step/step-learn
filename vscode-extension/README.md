# STEP Learn for VSCode

STEP Learnと連携して動く拡張機能です

STEP Learnへのアクセス権がないとこの拡張機能は意味をなしません

## 自動配布機能

### 使い方

1. この拡張機能を VS Code に入れます
2. STEP Learn でファイル自動配布のアイテムを開き、「VS Code で開く」を押します
3. ブラウザが VS Code を開いてよいかを確認したら、許可します
4. 初めてのサーバーのときは「ファイルを受け取りますか？」と聞かれるので、「受け取る」を押します

ファイルは `ドキュメント/STEP Learn/<コース名>/<アイテム名>` に用意され、そのフォルダーが VS Code で開きます。同じコースに同じ名前のアイテムがあるときは、あとから開いたほうを `<アイテム名> (2)` のような別のフォルダーに用意します。

### 2 回目から

- もう一度「VS Code で開く」を押すと、前に用意したフォルダーをそのまま開きます
- 先生がファイルを追加・更新していたときは、取り込むかどうかを聞きます。取り込んでも、自分で書き換えたファイルは上書きしません
- 「別のフォルダーに用意し直す」を選ぶと、`<アイテム名> (2)` のような新しいフォルダーに最初の状態で用意します

### データの同期

先生が「データを同期する」にしたアイテムでは、用意したフォルダーのファイルを保存するたびに、その内容が STEP Learn に送られ、変更履歴として記録されます。記録は先生と自分が、STEP Learn の画面から見られます。

- 最初に「データを同期するアイテムです」と確認します。「同期して続ける」を押すまで、内容は送りません
- 同期しているあいだは、ステータスバーに「STEP Learn 同期中」と表示します
- 送るのは、用意したフォルダーの中の文字のファイル（1 つ 256KB まで）です。`.git`・`node_modules`・`__pycache__`・`.venv` などと、画像などの文字でないファイルは送りません。フォルダーの外のファイルは送りません
- ネットワークにつながっていないときは、つながったあとにまとめて送ります
- 「STEP Learn 同期できません」と表示されたら、STEP Learn の画面の「VS Code で開く」をもう一度押してください

### 設定

| 設定 | 内容 |
| --- | --- |
| `stepLearn.folder` | ファイルを用意する場所。空のときは「ドキュメント/STEP Learn」 |

### コマンド

- **STEP Learn: 配布ファイルの保存先を開く** — 用意したファイルの場所をエクスプローラーで開きます
- **STEP Learn: ファイルを受け取ってよいサーバーの記録を消す** — 「受け取る」を押したサーバーの記録を消します

## コーディングエージェント

先生が用意した「コーディングエージェント」のアイテムでは、VS Code のサイドバーで AI に頼んで、開いているフォルダーのファイルを読み書きしながらプログラムを書いてもらえます。

### 使い方

1. STEP Learn でコーディングエージェントのアイテムを開き、「VS Code で使う」を押します
2. ブラウザが VS Code を開いてよいかを確認したら、許可します（初めてのサーバーでは「受け取る」も押します）
3. 右側のサイドバーに「STEP Learn」が出ます（VS Code 1.106 より前では、左のバーに出ます）。使える期間の外では出ません。閉じたときは、右下のステータスバーの「STEP Learn AI」から開けます
4. 作業するフォルダーを開いて、頼みたいことを書いて送ります

- AI はフォルダーの一覧を見る・ファイルを読む・探す・作る・書き換えるを、自分で選んで行います
- AI がファイルを書き換えた依頼のあとには、書き換えたファイルの一覧が出ます。「差分を見る」で依頼の前と今を並べて見られ、「変更を元に戻す」でその依頼の前の内容に戻せます（VS Code を閉じるまで）
- AI は、VS Code の「問題」に出ているエラーと、自分がターミナルで実行したコマンドの出力を読めます。ターミナルでエラーが出たら、「エラーを直して」と頼むだけで伝わります
- エディターで開いているファイルの場所と、選んでいる行の中身は、依頼と一緒に AI に伝わります。「このコードを説明して」のように頼めます。入力欄の上のファイル名を押すと、伝えるかどうかを切り替えられます
- 入力欄で `@` を打つと、開いているフォルダーのファイルの候補が出ます。選ぶと `@src/main.py` のように入り、AI がそのファイルを読みます
- 入力が要るプログラム（`input()` など）は、AI が入力を付けて実行します。付けた入力は、実行の確認に出ます。60 秒たっても終わらないプログラムは止めます
- コマンド（プログラムの実行など）は、毎回「実行する」を押したときだけ実行します。実行した出力は、会話に出ます
- 上に、使える量のうちどれだけ使ったか（利用）と、会話の長さを出します。会話が長くなると、それまでの内容を自動で要約して続けます
- 会話は、開いているフォルダーごとにこの PC に保存され、VS Code を開き直しても続きから使えます。最初からにするときは、右上の ＋（新しいチャット）を押します
- 使える量の上限に達すると、そのアイテムでは使えなくなります

### コマンド

- **STEP Learn: コーディングエージェントを開く** — サイドバーを開きます
- **STEP Learn: 新しいチャット** — 会話を最初からにします
- **STEP Learn: コーディングエージェントの接続を解除する** — この PC で使えなくします

## 安全のために

- ファイルを受け取るのは、STEP Learn の画面から開いたリンクに書かれたサーバーだけです。初めてのサーバーでは必ず確認します
- リンクに含まれる鍵は数分で切れ、1 回しか使えません。パスワードを拡張機能に入れることはありません
- 前に開いたときと違うアカウントのリンクを開くときは、そのアカウントの名前を出して確認します。ほかの人から送られたリンクで、保存した内容がその人の変更履歴に記録されないようにするためです
- 用意するフォルダーの外にはファイルを書き込みません。受け取ったファイルは、STEP Learn が示したハッシュと照らし合わせてから書き込みます
- コーディングエージェントが読み書きするのは、開いているフォルダーの中だけです。コマンドは、内容を見せて「実行する」を押したときだけ実行します
- コーディングエージェントを使えるあいだ、VS Code のターミナルで実行したコマンドと出力を、最近の 3 回分だけ覚えます。AI に送るのは、AI が読もうとしたときだけです
- コーディングエージェントのトークンは VS Code の安全な保存場所（SecretStorage）に置きます。AI の API キーは拡張機能に渡りません
